How it works

Three steps, about a minute

1

Photograph the board

Analog clock boards, printed or handwritten timetables, and screens. The photo is read on the phone.

2

Check every time

Each time is pinned on the photo. Anything the app wasn’t sure of is marked Please check. Tap to fix.

3

Send it

The masjid’s server gets the times and when the photo was taken, so stale photos can’t overwrite fresh times.

Reading the board

Built for real masjid boards

The app finds each clock on a board even through glass, glare and reflections, reads its hands, works out AM and PM, and figures out which clock is which prayer from the layout and the time of day. A bigger “current time” clock is read too and compared with the photo’s timestamp, which is a quick check that the photo is fresh.

  • Analog clock boards, one clock per prayer
  • Printed, written and on-screen timetables, in rows or columns, with or without separate adhan columns, prayer names in English or Arabic
  • Readings it isn’t sure of are flagged, never silently guessed
  • The time the photo was taken comes from the camera and can’t be edited

For masajid

A server you can run yourself

The example server is a complete, small service for one masjid, with no dependencies and one SQLite file. Deploy it on any small VPS in a few minutes.

  • Approve volunteers: anyone can register in the app, but only people you approve can update times
  • Maghrib from sunset, or a few minutes after, if your board’s Maghrib clock isn’t kept up to date
  • A widget for your website in one line of HTML, plus JSON for your own designs
  • Announcements: drafts a “prayer times are changing” post in your announcement list when the times really change
  • Every update kept with its photo, so you can always check it

On your website

Times that update themselves

Add one line to any page and the masjid’s current iqamah times appear, styled in dark or light, with the next prayer highlighted and Maghrib labelled when it follows sunset.

<script src="https://your-server/widget.js" async></script>

Or an iframe, or the raw JSON at /prayer-times.json for your own design.

Open

An open API, so any masjid website can join

The API

Five small JSON endpoints: register, sign in, check approval, send times, read times. An OpenAPI description is included.

The directory

List your masjid in the app with a one-file pull request, so volunteers can pick it instead of typing an address.
